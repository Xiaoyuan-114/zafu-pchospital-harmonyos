表单从列表中独立展开，移除填写时无关的筛选和刷新入口。返回时空表单直接回列表；有输入时先确认；提交期间保留页面。修改字段后清除该字段的旧校验提示。结果不明时保留原提交内容和幂等键，允许重试或返回列表核对。成功提交后回到“全部”，切换状态时清除旧的成功提示。

## 模拟器操作

Pura 90、HarmonyOS API 24、1320 × 2856；模拟器连接本机 API `13080` 和独立课设库 `pchospital_exp_forum_ui_20261103`。截图中的 `E2-*` 数据和电话号码是本轮验收数据。

- 点击空表单提交，机型、故障、电话分别显示必填提示；输入机型后对应提示消失，其余字段提示保留。
- 填写后点击页头返回，出现确认面板；选择继续填写，内容保留，补全后成功提交。再次填写并选择放弃，返回列表。
- 在“已完成”空列表进入报修，提交成功后回到“全部”，新单显示待受理；切换筛选后成功提示消失。
- 打开新单详情，设备、故障、联系电话及待受理时间线与提交内容一致，页头返回列表。
