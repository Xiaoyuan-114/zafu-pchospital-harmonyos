## 实际操作

- 改前通过模拟器提交第一条合成报修，列表显示提交成功，返回服务页仍显示“暂无报修设备”。重启 App 后同一服务页读取到该设备，保存同数据改前截图。
- 最终 HAP 通过模拟器提交第二条合成报修，返回服务页立即显示 `E-UI-Second` 和待受理；点击设备卡进入该单的报修详情，故障描述与待受理状态对应。
- 切换到工作人员账号，工作台摘要和成员活动入口仍可显示；之后恢复客户账号。两条报修均为独立课设库中的可识别验收数据。
- 正在读取设备时发生提交：回归测试验证旧请求结束后追加一次刷新；退出登录后的迟到响应不会回填旧设备。提交失败不会触发设备刷新。
