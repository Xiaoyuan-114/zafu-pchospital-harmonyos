知识首页增加醒目的搜索入口，保留问诊主行动与真实故障分类。搜索输入等待 350 ms 后请求，切词立即清除旧结果，筛选或提交立即搜索，离开时取消待执行请求。指南阅读将常见 Markdown 表格转成逐行字段，将提示标记和图片引用转成可读文字；代码块保留原文。收藏失败在按钮附近显示，正文继续可读；指南已失效时清除正文并显示服务端提示，成功提示也位于按钮附近。

## 实际操作

- Pura 90 模拟器（API 24，1320 × 2856）：从服务进入知识首页，展开“开机故障”，打开真实的《开机黑屏》；阅读章节、窄屏表格，返回后继续搜索。
- 搜索“开机”得到 3 条真实公开指南，打开结果后返回仍保留关键词；切换案例显示 0 条，清空关键词回到搜索引导。客户在《介绍》末尾收藏，按钮附近显示“指南已收藏”。
- 游客搜索案例显示登录入口；登录工作人员后保留“开机”和案例筛选，返回授权结果；随后恢复客户验收账号。角色权限及案例数据继续由服务端判断。
- 本地实验后端原先缺少知识索引，按仓库已有来源清单生成关键词索引并放入该本地后端原本缺失的位置；15 篇公开快照、1 篇内部测试资料，共 135 个分段。公开指南接口返回 15 篇；未调用向量服务，数据库仍为独立课设库 `pchospital_exp_forum_ui_20261103`。索引版本和生成结果见 [索引日志](index.log)。

最终 HAP 构建并安装成功，SHA-256 `4C3EE5EDCA22195C2CBA14AE841D00E45E7084D0A9F5ADAFD6204782EFF5D7F6`；[构建日志](build.log)。相关测试 21 项通过，两个改动测试文件 ESLint 通过，见[测试日志](tests.log)。首页、搜索结果和阅读截图取自最终包；其他状态截图取自此前构建，最后一次改动保留无数据行的表格原文。
