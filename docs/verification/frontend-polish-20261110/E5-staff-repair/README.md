## 改动

- 工作人员队列保留“待受理／我负责／全部”范围，给“我负责”和“全部”增加服务端状态筛选；切换范围时重置状态筛选，分页继续使用当前范围与状态。
- 列表卡片补“查看详情”操作线索，空态按实际筛选显示。队列在详情操作后刷新，受理后公共队列移除该单，“我负责”显示该单。
- “完成维修”增加二次确认与取消路径，明确维修处理状态与维修备案审核分离；成功后仍可建立备案。
- 修正共用提示条的动态文字传递，切换范围后显示对应队列说明。

- 页头返回和系统返回均返回队列；受理后返回公共队列见空态，“我负责”见新单。已受理状态筛选见空态，已完成筛选见该单。完成后客户详情接口返回 `COMPLETED` 与 4 条进度事件；工作人员 `scope=mine&status=COMPLETED` 返回该单；客户访问工作人员队列返回 HTTP 403。
