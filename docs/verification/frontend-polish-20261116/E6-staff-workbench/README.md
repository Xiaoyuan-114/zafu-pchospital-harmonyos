## 本地改动

- `ServicePage.ets`：工作人员入口按报修、备案审核或备案、成员活动、知识、案例、管理排列；入口位于统计之前。入口仍根据现有角色权限生成。
- `WorkbenchSummary.ets`：沿用 `/api/v1/member/dashboard` 真实字段，把本人备案的草稿、审核中、已退回与维修贡献分开展示；保留“待配置”和各子区域降级信息。刷新时保留已有内容，响应只接受最后一次请求。
- 客户服务页的入口顺序和目标未改。
