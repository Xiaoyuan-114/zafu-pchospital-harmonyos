## 调整与实际操作

- 活动频道收紧主题横幅，去除每条卡片重复插画，突出真实标题、时间、状态和名额；搜索无结果提供清空入口，未知活动状态采用中性文案。
- 详情缩短头图并保留真实时间、地点、名额、条款和底部报名入口。本人列表突出状态、时间及掩码联系人，卡片进入对应报名；错误时不显示误导性的零条记录。
- 客户实际填写报名、同意当前服务端条款并提交，查看本人报名；返回频道后显示从 1 增至 2 条、剩余 28 名。客户本人列表中两条不同联系人均可区分，点击其中一条进入对应详情。
- 游客从详情发起报名，登录后续接相同活动的报名表单。切换到工作人员账号后本人列表为空，没有带出客户记录；之后已恢复客户账号。论坛频道切换并正常显示真实帖子。
- 模拟器为 Pura 90、1320 × 2856、API 24，浅色主题。数据使用独立课设库 `pchospital_exp_forum_ui_20261103` 和本机 API `10.0.2.2:13080`；管理员 API 创建的活动名称带“界面验收样本”标识，一条报名由客户 API 创建以建立对照，另一条由模拟器表单创建。
