## 5. 审查问题与修复

独立代码审查发现三项合并前问题，均已修复并重跑上述检查：

- 软删帖子/评论仍可能通过幂等重放以 201 返回旧内容：现在帖子、评论及父帖删除态均在重放前检查，统一返回 404；评论事务内也复核父帖。新增评论单删重放、删帖后评论重放和删帖创建重放回归。
- 同一 multipart 内重复 `uploadKey` 可能触发二次唯一冲突并变成 500：现在写存储前拒绝重复键，返回 400，新增同图/不同图与 API 回归。
- malformed multipart 被映射成 500：现在格式错误返回 400，可识别的 body 超限返回 413，新增实际路由回归。

非阻塞观察尚未扩大处理：同键并发创建/上传的直接回归仍可补充；集成测试的图片目录仍可进一步隔离。现有测试通过不表示这些补充工作已完成。
