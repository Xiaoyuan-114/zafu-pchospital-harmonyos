## 6. 每批固定工作流

1. **打开参考图与当前页面。** 在模拟器保存本批改动前画面，记下代码 SHA、未提交差异、角色、API、数据对象与滚动位置。先列具体问题及预期结果。
2. **只实现这批页面。** 先修流程断点和反馈，再调布局、字重、图标、间距、圆角。涉及未知产品行为或缺接口时带具体问题与用户对齐。
3. **构建并安装 HAP。** 从当前 worktree 的 `app/` 构建，安装该产物；记录包的 SHA256、构建日志、设备型号/系统/尺寸与安装结果。
4. **逐个改动页面实际操作。** 页头返回和系统返回分别走；列表/详情/提交后同步；涉及输入的页检查键盘遮挡；共享组件改变时覆盖其受影响的消费者。
5. **保存改后截图与短操作记录。** 与改前保持相同角色、数据、滚动位置和页面状态；另保存本批改变的空态、错误恢复、弹层等关键状态。动画/重复点击/迟到回调用操作序列或短录屏记录。
6. **本地审阅这一批，再提交 PR 复审。** 先修完本地发现的阻断问题，再提交参考图、改前、改后及操作记录；收到 PR 意见后修正受影响代码与证据。审查问题未闭环时优先处理当前块，不继续扩大跨模块改动。

每页检查矩阵：

| 检查项 | 记录内容 |
| --- | --- |
| 布局与文字 | 与参考图同宽归一化比对标题/正文比例、基线、边距、卡片高度、字重、长标题换行/省略 |
| 图标与图片 | 线宽、尺寸、彩色/线性图标用途、真实图片裁切、缺图；操作图标的可访问名称 |
| 触控与导航 | 点击区域、重复点击、页头/系统返回、Tab 滑动、弹层关闭、登录成功/取消续接 |
| 动态效果 | 260ms 原生 Tab 切换、减少动态效果设置；提交/加载/展开反馈、切页过程 |
| 数据状态 | 初次加载、真实空态、无搜索结果、失败重试；刷新失败保留已有内容，防止旧请求覆盖新筛选 |
| 写操作 | 校验、提交中、成功/失败、重复提交、返回后同步；下单/上传保留现有幂等与会话保护 |
| 角色 | 游客、客户、工作人员；仅在本批触及审核/管理时增加对应授权账号 |
