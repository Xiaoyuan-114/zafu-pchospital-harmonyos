## 页面映射与证据边界

- 本项目的客户服务首页可参考“服务”页的设备卡片、维修入口和进度入口；具体字段、权限及状态以本项目[需求基线](../../requirements-baseline.md)和[原项目盘点](../../source-audit.md)为准。
- 本项目“我的报修”可参考“我的”页内“服务记录”入口的发现方式，但两者业务对象不同，不能把参照 App 的“服务记录”直接等同于本项目的客户报修单或 `RepairRecord`。
- 首页、选购与花粉社区仅用于顶层导航、分类和内容组织对照。
- 这组截图没有记录完整的逐次点击过程，也没有 App 版本及设备系统信息；目前只核验了截图中可见的入口，**参照链路尚未完整核验**。
