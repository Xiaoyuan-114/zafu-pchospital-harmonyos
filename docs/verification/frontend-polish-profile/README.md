## 修改与检查

账号卡的头像与姓名区域打开个人资料；工作人员的报修队列入口命名为“报修工作台”；入口文字允许换行并留出间距。客户报修统计不再通过点击整块区域刷新，出错时仍可使用错误面板的重试按钮。

在 Pura 90 模拟器（1320 × 2856）安装 HAP，使用本机课设后端和测试客户、工作人员账号：

- 两种身份均从账号卡进入个人资料；客户进入个人信息后关闭并返回“我的”。
- 客户从账号卡进入“我的报修”并返回；从入口区进入购物订单、我的帖子和站内消息，各页面显示对应标题。
- 客户首屏显示本人最近一页报修统计；入口区保留“维修记录暂未接入”的说明。
- `assembleHap` 构建成功，详见 [构建记录](build.log)。

本轮没有覆盖资料保存、报修统计错误重试、管理员权限组合、其他入口逐项跳转和实体手机；工作人员资料截图采自入口文字宽度微调前的版本。
